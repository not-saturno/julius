# 💸 Julius Bot

> "Se eu não comprar nada, o desconto é maior."

O **Julius** é um bot de Discord focado em rastreio de preços de jogos e hardware para o mercado brasileiro. Ele foi feito para quem quer economizar de verdade e não tem um dólar (ou real) a mais para gastar com preços abusivos.

## 🚀 Funcionalidades
- **Rastreio de Preços:** Monitora lojas como Steam, Nuuvem e mais.
- **Foco em BR:** Feito por brasileiro, para brasileiro.

Confira os comandos, guia de instalação e como apoiar o projeto em:

- Java 17 + Spring Boot
- JDA (Java Discord API)
- MkDocs (Documentação)
